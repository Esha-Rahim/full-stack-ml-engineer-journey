## Topics Covered

### 1. Matrix Fundamentals
- Definition of a matrix
- Intuition behind matrices
- Rows and columns in a matrix
- Matrix dimensions
- Matrix shape: number of rows × number of columns
- Difference between matrix dimensions and matrix shape

### 2. Matrices in Machine Learning
- How feature vectors form a matrix
- Representing an ML dataset as a matrix
- Samples (observations) and features
- The feature matrix, X
- The target vector, y
- Difference between a feature matrix and a target vector
- Relationship between dataset shape and number of samples
- Relationship between dataset shape and number of features

### 3. NumPy Array Structure
- One-dimensional arrays vs. two-dimensional arrays
- NumPy array shape: shape
- Number of dimensions: ndim
- Number of elements: size
- Inspecting dataset shape using NumPy
- Selecting rows and columns from a matrix
- Matrix indexing and slicing
- Transposing a matrix: basic intuition

### 4. Dataset Shape and Model Inputs
- How dataset shape affects ML model inputs
- Assumptions when representing a dataset as a matrix
- Implementation choices for matrix representation

### 5. Common Failure Modes
- Confusing rows with columns
- Incorrect array dimensions
- Mismatched feature and target shapes
- Misunderstanding a one-dimensional array versus a two-dimensional array

### 6. Why This Matters for an ML Engineer
Understanding matrices and dataset shape helps an ML Engineer inspect data correctly, distinguish samples from features, prepare inputs for machine learning models, and identify shape-related errors before or during implementation.
